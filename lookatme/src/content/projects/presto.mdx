## Overview

Presto is a presentation builder that runs in the browser, inspired by Slides.com. It lets a signed-in user create slide decks, edit them slide by slide, and share the result — without installing desktop software.

## What the screenshot shows

The dashboard above is an actual screenshot of the application: a signed-in session, saved presentations shown as cover cards, and a **New Presentation** action for starting a fresh deck. It is presented as-is; no interface has been mocked up for this page.

## The editor

Presto is a **React and TypeScript single-page application**, built with Vite and routed with React Router. The frontend talks to a REST API for authentication and for persisting presentation state, so a deck survives a session rather than living in browser memory.

Inside the editor: rich slide elements, **drag and resize** interactions for positioning them, slide reordering, configurable backgrounds, and a preview mode — the working set of a lightweight presentation tool rather than a static viewer.

## Revision history

The feature worth calling out is **timestamped revision history**. Snapshots are throttled to a minimum one-minute interval so that normal editing does not flood the history, and any snapshot can be restored. It turns the editor from something you can break into something you can back out of.

## Testing and deployment

Key user journeys are covered by **Cypress end-to-end suites** — authentication, the presentation lifecycle, editor actions, error paths, and restoring a revision. The completed frontend is deployed to **Vercel**.
