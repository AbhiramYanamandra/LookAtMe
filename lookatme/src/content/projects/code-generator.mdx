## Overview

A generator for the **ADFGVX cipher**, the First World War field cipher that combines a Polybius-square substitution with a columnar transposition. Type a message in, get the enciphered text out.

<Note>
  A short programming exercise. The language, whether decryption is supported, and how the key is supplied are not yet documented here.
</Note>
