## Overview

A pipelined, MIPS-style processor split into the classic five stages — **Fetch, Decode, Execute, Memory, and Writeback** — with pipeline registers between each stage so several instructions are in flight at once.

## The BNE extension

The base design was extended to support the **Branch Not Equal (BNE)** instruction, which requires the branch-decision logic to act on the ALU's comparison result and steer the program counter accordingly.

## About the diagram

The datapath diagram at the top of this page is the **standard textbook five-stage pipeline** with its control signals. It is shown to explain the architecture the project follows; it is not the project’s own schematic or a simulation screenshot. The simplified five-box illustration on the homepage card is likewise an explanatory graphic, not implementation evidence.
